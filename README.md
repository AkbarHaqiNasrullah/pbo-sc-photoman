# Program Data Karyawan SC.PHOTOMAN (Pemrograman Berorientasi Objek)

Project mata kuliah Pemrograman Berorientasi Objek (PBO) dengan Python. Program pengelolaan data karyawan dan gaji untuk usaha SC.PHOTOMAN, dengan bidang Fotografer, Videografer, Editing, dan Dekorasi.

## Isi Repository

| File | Keterangan |
|---|---|
| `sc_photoman.py` | Program utama berbasis menu: input, lihat, dan hapus data karyawan |
| `pbo_karyawan.py` | Penerapan konsep OOP: inheritance, class variable, dan static method untuk menghitung jumlah, total, dan rata-rata gaji |
| `versi_awal.py` | Versi awal program menu (bidang diinput dengan mengetik nama) |

## Konsep OOP yang Diterapkan

- Class dan Object
- Constructor (`__init__`)
- Inheritance (pewarisan class)
- Class variable
- Static method

## Fitur Program Utama (`sc_photoman.py`)

1. Input data karyawan (nama dan bidang), gaji terisi otomatis sesuai bidang
2. Check data karyawan
3. Hapus data karyawan berdasarkan nama
4. Keluar program

| Bidang | Gaji |
|---|---|
| Fotografer | Rp 1.000.000 |
| Videografer | Rp 2.000.000 |
| Editing | Rp 2.500.000 |
| Dekorasi | Rp 1.500.000 |

## Teknologi

- Python 3

## Cara Menjalankan

```
python sc_photoman.py
python pbo_karyawan.py
```
